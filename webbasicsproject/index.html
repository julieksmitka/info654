What is this?

As part of INFO-654: Information Technologies, a course at Pratt Institute, students are tasked with creating a website. For this assignment, there are 24 requirements, one of which is the inclusion of an image that links to an external website.

Other requirements include:

  • an unordered list
  • a list that is nested
    • that is, a list within a list
    • useful when communicating hierarchies, like this
  • a table, with any content, using either table tags or div tags

HTML & CSS
The web site demonstrates effective use of the technologies and design techniques explored in class, going significantly beyond course materials and requirements. Site is entirely free of validation errors.
The web site demonstrates effective use of the technologies and design techniques explored in class, going beyond course materials in a few instances. Site includes an occasional validation error or could have been implemented in a better way.
The web site demonstrates some use of the technologies and design techniques explored in class. Site includes significant validation errors.
The web site fails to make use of the technologies and design techniques explored in class.
Content
The web site has a clearly-stated purpose, supported by consistent and extensive content.
The web site has a well-stated and clear purpose. Content is developed in-depth throughout the web site.
The web site has a clearly stated purpose and theme, but may have several content elements lacking in depth.
The purpose of the web site is vague and content is poorly developed or missing.
Technical Requirements
All directions followed exactly, e.g. file naming conventions, HTML validated, all CSS styles in external style file, etc.
Most directions followed, e.g. file naming conventions, HTML validated, CSS placement, etc.
Some directions followed, e.g. file naming conventions, HTML validated, CSS placement, etc.
Few or no directions followed, e.g. file naming conventions, HTML validated, CSS placement, etc.
