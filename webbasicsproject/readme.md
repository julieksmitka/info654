## Description of Topic
You will be creating a website using the HTML and CSS skills we have learned. The specific content that you include is up to you, but you may include: work experience, areas of expertise or interest, personal information, career goals, hobbies, etc.  It is fine if the entire site contains fictitious information. For submission, your site will be uploaded to GitHub pages. (detailed instructions will be given in class) and the URL for your site will be submitted for grading.

## Requirements
- Every page should render well on different  screen sizes - so the pages must be designed with responsive considerations, even if it is not perfect. Images and other elements on the page must also be responsive.
- Every page must be well structured (e.g., HTML pages contain head and body sections, etc.).
- Files created should have names that are logical and easy to follow.
- There should be no extraneous tags or code in each html or css document. Every tag should have a purpose.
- Must adhere to copyright law. Use your own multi-media work or freely reusable images (e.g. http://libguides.mit.edu/c.php?g=176183&p=1159045) where desired.
### HTML:
- Must include a page named index.html (as your site’s homepage)
- Should include additional HTML files as necessary to build out your site (for a total of 3 to 5 pages), e.g. resume.html, all relatively linked through some form of navigational section
- Your html file(s) must be implemented using HTML5 and must validate according to the http://html5.validator.nu/ validator.
- Within your site, include at a minimum:
  - Several paragraphs
  - One table (with any contents) using either the table tags or div (more points if using div only)
  - One unordered list (with any contents)
  - A list that is a nested list (with any contents)
  - One link to an external website (clicking on text)
  - One link to an external website (clicking on an image)
  - Other links and images, as appropriate
  - Copyright symbol, your name, and the current year at the end of every page
 
### CSS:
- Your HTML files should link to your external css file in the head of your file (e.g., <link rel="stylesheet" type="text/css" href="screen.css">) and all CSS styles should be contained in this one external CSS file.
- Your CSS file must validate according to the http://jigsaw.w3.org/css-validator/ validator.
- In your CSS styles, you should at a minimum:
  - Define and use one name selector, e.g. p {…}
  - Define and use one id selector, e.g. #footer {…}
  - Define and use one class selector, e.g. .description {…}
  - Use CSS to generally style your page(s), e.g. to control border, width, color, background-color, font style, font size, layout and positioning, etc. (avoid in-line styling)
*Note: You may not use any authoring tool that generates the code for you. You must implement this assignment by yourself; it is fine to ask the instructor/tech tutor for help but do not copy HTML or CSS directly from online sources or classmates.*
